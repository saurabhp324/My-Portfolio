# My-Portfolio
A personal portfolio website showcasing my skills, projects, and contact information. Built using HTML, CSS, Bootstrap, and JavaScript with a responsive and modern design.
## Features

- Responsive design
- Modern UI
- About Me section
- Skills section
- Projects section
- Contact form
- Social media links
- Resume download

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
